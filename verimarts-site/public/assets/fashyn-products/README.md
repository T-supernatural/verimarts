# FASHYN product imagery

Approved product images can be added here without changing application code.

Use this naming convention:

```text
<product-slug>--<position>--<short-description>.<extension>
```

Examples:

```text
linen-shirt--01--front.webp
linen-shirt--02--detail.webp
```

Use WebP or JPEG where possible. Keep each product's images together, preserve the numeric position, and provide approved alt text when the catalogue data is created. Do not add unlicensed or unapproved imagery.
